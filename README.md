Étudiant à 42 Paris, ancien couvreur.

J'ai toujours monté et bidouillé mes propres machines : assemblage, BIOS, installation de systèmes, overclocking. Après 11 ans sur les toits, dont plusieurs à la tête d'une équipe, j'ai voulu comprendre ce qui se passe de l'autre côté, dans le code.

Depuis, j'aime refaire les outils que j'utilise pour comprendre comment ils fonctionnent : un shell, un serveur IRC, un moteur 3D, et maintenant des applications web.

### Projets

**[minishell](https://github.com/Skulay/minishell)** · C\
Mon propre bash, écrit en binôme : quotes, pipes, redirections, heredoc et signaux.\
J'y ai appris à gérer des processus proprement et à traquer chaque fuite mémoire avec Valgrind.

**[ft_irc](https://github.com/Skulay/IRC)** · C++\
Un serveur IRC qui gère tous les clients sur un seul thread, avec une boucle epoll.\
Le plus intéressant a été de gérer les messages qui arrivent en morceaux et les déconnexions brutales. On s'y connecte avec un vrai client comme irssi.

**[ft_transcendence](https://github.com/rasiolisufaj/ft_transcendence)** · TypeScript, Next.js\
Une application web développée à 4, qui aide à gérer ses démarches administratives avec de l'IA.\
Mon premier vrai projet en équipe : se répartir le travail, relire le code des autres, livrer ensemble.

**[cub3D](https://github.com/Skulay/Cub3D)** · C\
Un petit moteur façon Wolfenstein 3D, en raycasting.\
Murs texturés, déplacements et collisions, à partir d'une carte lue dans un fichier.
